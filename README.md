# 🏛️ Roman Museum - 3D Immersive Experience

A modern, immersive 3D website featuring a Roman aesthetic, built with **React**, **Three.js**, and **Tailwind CSS v4**. This project showcases high-performance 3D model rendering, post-processing bloom effects, and smooth GSAP scroll animations.

## 🚀 Tech Stack

* **Framework:** [React](https://react.dev/) + [Vite](https://vitejs.dev/)
* **Styling:** [Tailwind CSS v4](https://tailwindcss.com/) (using CSS Variables configuration)
* **3D Engine:** [Three.js](https://threejs.org/)
* **Animations:** [GSAP](https://gsap.com/) (ScrollTrigger)
* **Smooth Scroll:** [Lenis](https://lenis.darkroom.engineering/)

## ✨ Features

* **3D Integration:** Interactive GLTF model loader with custom lighting and materials.
* **Post-Processing:** UnrealBloomPass implementation for glowing emissive effects.
* **Scroll Animations:** Synchronized camera movement and 3D object rotation on scroll.
* **Parallax Gallery:** High-performance image gallery with parallax effects using GSAP.
* **Custom Preloader:** React-based loading state handling asset initialization.
* **Responsive:** Fully responsive layout using Tailwind's utility classes.
